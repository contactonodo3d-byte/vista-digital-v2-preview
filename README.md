# Vista Digital V2 — feedback preview

A responsive, 26-page concept for Vista Digital.

Live preview: https://contactonodo3d-byte.github.io/vista-digital-v2-preview/

The growth assessment uses animated demonstration data and does not perform a real website scan. Contact forms prepare an email draft; they do not submit data. Verified proof placeholders remain where results have not been supplied.

The static website is in `docs/` and is published through GitHub Pages.
